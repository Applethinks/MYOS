# MYOS — Make Your Own Site

## Helping ideas find their place online.

MYOS is a growing, youth-led web development venture focused on helping small businesses, shops, restaurants, and individuals establish their presence online.

## What We Do

- Business websites
- Restaurant websites
- Custom website projects
- Interactive webpage-building demonstrations

## Our Mission

We want to make getting a website simpler and more approachable for people who don't know where to start.

We work toward creating websites that fit each customer's needs, goals, and proposed budget.

Built With

- HTML
- CSS
- JavaScript

Project Status

MYOS is currently under development.

We're building the website, creating interactive demonstrations, and preparing our project enquiry system.

Our Vision

To help more people discover what's possible on the web, one idea at a time.
